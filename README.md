# 📊 AJ Slides (Apresentações)

Bem-vindo ao repositório do projeto de **Apresentações**! Este sistema foi construído para criar e exibir slides de forma moderna, rápida e responsiva.

## 🚀 Tecnologias Utilizadas

Este projeto foi desenvolvido com foco em alta performance e uma ótima experiência de desenvolvimento (DX), utilizando o que há de mais moderno no ecossistema front-end:

- **[React 19](https://react.dev/)** - Biblioteca principal para construção de interfaces.
- **[Vite](https://vitejs.dev/)** - Ferramenta de build e servidor de desenvolvimento incrivelmente rápido.
- **[TypeScript](https://www.typescriptlang.org/)** - Superset do JavaScript que adiciona tipagem estática e segurança ao código.
- **[Lucide React](https://lucide.dev/)** - Pacote de ícones limpos, consistentes e modernos.
- **[Oxlint](https://oxc.rs/)** - Linter super rápido para manter a qualidade e padronização do código.

## 🛠️ Como executar o projeto localmente

Siga os passos abaixo para rodar o projeto na sua máquina:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/Araujaum7/apresenta-es.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd apresenta-es
   ```

3. **Instale as dependências:**
   ```bash
   npm install
   ```

4. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

5. O projeto estará rodando (geralmente na porta `http://localhost:5173`). Abra o link no seu navegador para visualizar!

## 📦 Scripts Disponíveis

No diretório do projeto, você pode rodar os seguintes comandos:

- `npm run dev`: Inicia o servidor local de desenvolvimento.
- `npm run build`: Compila o TypeScript e gera a versão de produção (otimizada) pronta para deploy (pasta `dist`).
- `npm run preview`: Inicia um servidor local para você testar a versão de produção antes de subir.
- `npm run lint`: Verifica a qualidade do código buscando por possíveis erros de padronização.
